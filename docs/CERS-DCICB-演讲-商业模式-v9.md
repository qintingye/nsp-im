## 核心论点

**央企电网子公司**（南网能源、国网 e+、南网启成、南网看能等）的成熟商业模式与合作模式。

**4 大类**：
- **重资产投资运营**（BOO/BOT/EPC）
- **轻资产服务**（EMC/能源托管/VPP/售电+增值/能碳平台/算电协同）
- **平台交易**（南网启成 / 国网能源 e+）
- **股权生态合作**（合资公司 / 加盟合伙人 / 业主代运营 / 联合开发）

**转型方向**：重资产 → 轻资产（提升 ROE，匹配国企考核）。

---

## 一、5 大成熟商业模式

### 1. BOO 建设-拥有-运营（重资产）
- 全额投资，永久持有，20-25 年合同
- 收益：售电 + 峰谷套利 + 需求响应 + 绿电溢价
- 适用：园区/工厂/数据中心/公共机构
- 代表：南网能源工商业光储项目

### 2. BOT 建设-运营-移交（重资产）
- 投资建设，约定周期运营收费，到期移交
- 适用：医院/学校/政府园区

### 3. EMC 合同能源管理（轻资产）
- 电网子公司投资改造，客户零投入
- 按节约电费效益分成，到期资产无偿转给客户
- 适用：工业电机 / 中央空调 / 厂房屋顶光伏
- **重点推广方向**（政策鼓励）

### 4. 能源托管（全委托运营）（轻资产）
- 业主全部用能系统 + 运维 + 采购托管给电网子公司
- 支付固定/打包服务费
- 适用：医院 / 高校 / 轨道交通 / 大型园区
- **现金流稳定，不新增大额资产投资**

### 5. 虚拟电厂 VPP 资源聚合运营（极轻资产）
- 聚合分布式光伏/储能/充电桩/工业可调负荷
- 统一参与电力现货/辅助服务/需求响应市场
- 盈利：市场交易分成 + 平台服务费 + 代运营服务费
- **核心增长赛道**（南网启成 / 国网能源 e+）

### 6. 售电+增值服务一体化（轻资产）
- 基础购售电 + 负荷管理 + 绿电采购 + 碳资产 + 电力避险
- 不再单纯靠售电价差

### 7. 能碳数字化平台服务（极轻资产）
- 输出能源管理平台 / 碳核算 / 微网 EMS / 虚拟电厂调度
- 按项目 license / 年度服务费 / SaaS 订阅
- 代表：南网看能/启成，国网能源 e+
- **从卖硬件 → 卖软件订阅**

### 8. 算电协同服务（新兴成熟）
- 面向 AI 算力/智算中心
- 提供：绿电打包 + 负荷调度 + 储能配套 + 电力交易 + 能耗监测
- 收益：电力打包服务费 + 负荷调节收益 + 定制化能源方案费

## 二、3 大对外合作模式

### 1. 股权类合作

#### 1.1 合资公司共建（最常用）
- 电网子公司 + 地方平台/产业园区/工业企业/设备厂商
- 各方按股权出资，共担风险，共享收益
- 场景：零碳园区/共享储能/生物质/源网荷储一体化
- 电网输出：技术 + 电力市场能力
- 合作方输出：场地 + 资金 + 本地资源

#### 1.2 加盟/合伙人机制（绿电合伙人）
- 不成立股权公司，生态协议
- 政府出政策补贴，园区出屋顶场地，社会资本出资
- 电网子公司输出：规划 + 平台 + 运维 + 并网技术
- 各方按项目协议分成
- 适合：批量中小园区（国网江苏实践）

### 2. 契约合作模式（无股权）

#### 2.1 业主出资产 + 我方代运营
- 客户自有光伏/储能/充电桩资产
- 电网子公司负责运维 + 市场交易 + 调度优化
- 收取固定服务费或超额收益分成
- 当前 VPP/储能业务大量采用（**轻资产扩张路径**）

#### 2.2 租赁模式
- 电网子公司租赁客户屋顶/场地建设光储
- 支付场地租金，自持资产运营
- 客户获得：租金 + 优惠电价

#### 2.3 框架战略协议 + 项目落地
- 与地方政府/大型集团签战略框架
- 约定整体零碳 + 新型电力系统建设
- 后续分批次落地 BOT/EMC/托管项目

#### 2.4 PPP/特许经营（增量配网、园区微网）
- 政府授予园区微网/增量配网特许经营权
- 组建项目公司，负责园区内部源网荷储投资运营
- 收取内部配电服务费 + 综合能源服务费
- 多用于产业新区（门槛高，周期长）

### 3. 产业链生态合作

#### 3.1 技术联合开发
- 电网子公司 + 设备厂商 + 科技企业
- 联合开发 VPP/储能 EMS/碳管理产品
- 电网输出：场景 + 电力市场 + 测试条件
- 合作方输出：软硬件
- 成果市场化分成（如南网能源与华为/腾讯合作）

#### 3.2 渠道分包合作
- 电网子公司做总包总协调
- 引入工程/设备/运维合作伙伴分包实施
- 电网把控：方案 + 并网 + 交易 + 运营

## 三、模式对比与转型趋势

| 模式 | 资产属性 | 现金流 | 适用场景 | 电网子公司策略 |
|---|---|---|---|---|
| **BOO/BOT** | 重资产 | 长期稳定 | 大型园区/厂矿 | 严控新增，存量优化 |
| **EPC** | 重资产 | 一次性 | 工程交付 | 降占比，转"EPC+运营" |
| **EMC** | 中重 | 分期回收 | 节能改造 | 存量优化，优质客户 |
| **能源托管** | 轻 | 年度服务费 | 医院/学校/园区 | **重点扩张** |
| **VPP 代运营** | 极轻 | 交易分成+服务费 | 海量分散资源 | **核心增长赛道** |
| **售电+增值** | 轻 | 价差+服务费 | 工业/商业 | 升级套餐 |
| **能碳平台** | 极轻 | 订阅/license | 跨场景 | **从硬件→软件** |
| **算电协同** | 中 | 服务费+调节收益 | AI 算力 | **新兴成熟** |
| **合资共建** | 股权混合 | 按股权分红 | 大型标杆 | 优先鼓励 |
| **加盟合伙人** | 协议 | 项目分成 | 批量中小园区 | **规模化复制** |

**整体转型方向**：
- **从"重资产投资建电站"** → **轻资产运营/平台聚合/代运营/能源托管/股权合资**
- **减少自有资本占用，提升 ROE**
- **匹配国企考核导向**

## 四、4 大实操风险

| # | 风险 | 关键核查 |
|---|---|---|
| 1 | **业主信用风险** | BOO/BOT 重点核查业主信用 + 场地权属，规避电费拖欠 |
| 2 | **节能基准争议** | EMC 必须约定节能效益核算基准 |
| 3 | **VPP 权限边界** | 清晰约定资源调度权限 + 收益分成 + 安全责任 |
| 4 | **业务边界合规** | 严格区分电网公共业务与市场化子公司业务，规避合规风险 |
