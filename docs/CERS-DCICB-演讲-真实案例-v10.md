## 一、BOO / EMC（重资产投资，分布式光伏、储能）

### 案例 1：中山格兰仕屋顶分布式光伏｜南网能源，EMC
| 项 | 内容 |
|---|---|
| **模式** | EMC 合同能源管理 |
| **投资** | 南网能源全额投资 52.38MW 屋面光伏 |
| **业主** | 格兰仕（零资金投入）|
| **合同** | 25 年，优惠电价回收投资，期满资产无偿移交 |
| **收益来源** | 光伏自发自用电费价差 + 余电上网 |
| **成效** | 年发电 5000 万 kWh；年省电费 300+ 万；厂房降温 3-5℃ |

### 案例 2：广船国际 15MW/30MWh 用户侧储能｜南网能源，EMC
| 项 | 内容 |
|---|---|
| **模式** | EMC，全额投资储能电站 |
| **业主** | 广船国际（不出资）|
| **收益** | 峰谷套利 + 需量电费节省 |
| **亮点** | 大湾区船舶制造业最大用户侧储能 + 接入 VPP 平台 + 需响/辅助服务双方分成 |

### 案例 3：四川长虹经开区工业园能源站｜南网能源，BOO
| 项 | 内容 |
|---|---|
| **模式** | BOO 建设-拥有-运营 |
| **投资** | 南网投资冷热电三联供工业能源站，长期持有 |
| **业主** | 工厂按消耗支付冷/热/电能源使用费 |
| **适用** | 大型工业园区，不移交资产，赚长期能源服务费 |

## 二、能源托管 + VPP（轻资产，公共机构标杆）

### 案例 4：佛山禅城区全域公共机构项目｜南网能源
| 项 | 内容 |
|---|---|
| **模式** | **全国首个**行政区级"**托管+VPP**" |
| **资源** | 存量政府机关/学校/医院楼宇聚合（不建新硬件）|
| **责任** | 南网全托管运维 + 电力交易 + 节能改造 + 柔性负荷调度 |
| **盈利** | 打包能源服务费 + 电力交易价差 + VPP 需响收益分成 |
| **成效** | 全区公共机构统一聚合参与广东电力市场 + 购电成本下降 + 负荷统一调度 |

### 案例 5：南方医科大学珠江医院｜南网能源
| 项 | 内容 |
|---|---|
| **模式** | 能源费用托管型 EMC |
| **投资** | 4880 万改造空调/配电/热水/照明 |
| **业主** | 医院按原基准支付打包能源服务费，节约归服务商 |
| **配套** | 智慧能碳平台 + 设备远程运维 |
| **典型** | 医院/高校类公共机构托管样板 |

## 三、虚拟电厂代运营（极轻资产）

### 案例 6：国网江苏综合能源"能源 e+" 平台 VPP
| 项 | 内容 |
|---|---|
| **模式** | 代运营（不投资硬件，业主自持设备）|
| **资源** | 全省工商业光伏 + 储能 + 空调可调负荷 |
| **规模** | **近 4 万资源点，聚合容量 597 万 kW** |
| **盈利** | 平台服务费 + 需响/辅助服务收益分成 + 数百光伏打捆参与电力市场 |
| **特点** | 电网子公司典型轻资产扩张路径，**不新增重资产** |

### 案例 7：湖南星沙 VPP｜国网湖南综能 + 地方国资
| 项 | 内容 |
|---|---|
| **模式** | 合资共建 VPP 运营商 |
| **资源** | 园区储能 + 充电桩 + 中央空调可调负荷 |
| **场景** | 经开区迎峰度夏需求响应 |
| **收益** | 电网需响补偿 + 市场交易分成 |

## 四、股权合资模式

|---|---|

|---|---|

## 五、零碳园区"投资+平台"综合方案

### 案例 10：广州工控源网荷储零碳园区｜南网能源
| 项 | 内容 |
|---|---|
| **模式** | **综合打包**（不是单一项目）|
| **组成** | ① BOO 投资光储硬件 + ② EMS 能碳数字化平台 + ③ 绿电/绿证代理 + ④ 接入 VPP |
| **收入** | 能源销售 + 平台年度服务费 + 绿证交易佣金 + 需响收益 |
| **价值** | **咨询-投资-建设-数字化运营-碳交易全链条交付** |
