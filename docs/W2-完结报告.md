## 6. 风险与遗留

### 6.1 P0 (W3 必须修)

1. **国网 sgcc.com.cn 15s 超时**：站点对中国大陆 IP 不稳定或主动拦截。建议：
   - (a) 加大超时到 30s 并加重试；
   - (b) 接入 SGCC 公开 RSS 或第三方镜像；
   - (c) 与 SGCC 商务对接申请 API key。
2. **fetch_raw 真抓复用子类的实现**：`RealNdrcFetcher` 调用 `super().fetch_raw()`，这意味着真抓代码在 `NdrcFetcher` 内，不在子类内。重构时机：W3 把真抓函数从父类抽到独立模块 `src/fetchers/real/*.py`，让 `RealNdrcFetcher` 直接调纯函数。

### 6.2 P1 (W3 可做)

1. **doc_number 字段全空**：schema 允许 `null`，但失去按"文号"检索能力。需在 `parse()` 后增加详情页抓取 (a 链接 → 详情页正则)。
2. **抓取 cron 化未自动化**：`scripts/e2e_w2d5.sh` 需配合 cron 9:00 触发（建议放到 `~/.hermes/cron/jobs.d/` 由 Hermes scheduler 调度）。
3. **飞书 webhook 未接**：D4 `alert_failure` 留 TODO，需要 FEISHU_WEBHOOK 环境变量 + 发送实现。
4. **CSG/SGCC 真抓的关键词过滤过宽**：南网目前只看"通知/公告/招标/规划"等词，但首页大量非政策内容；需要按栏目路径 (`/xxx/tzgg/`) 抓取，而非首页锚点。

### 6.3 P2 (后续季度)

1. **解析质量**：南网/北极星目前抓"标题 + 日期"，缺正文 (`summary` 字段 = `title[:100]`)。需接入详情页正文抽取（`requests-html` 或 `trafilatura`）。
2. **多语言**：当前仅中文，未覆盖英文版发改委。
3. **跨源关联**：相同政策被 NDRC 和 NEA 同时发布时（如 "煤炭工业发展规划"），目前按 id 不同保留两条；可加内容指纹（simhash）做归并。
