## 1. 方案决策（Vercel → GitHub Pages）

| 项 | Vercel（原计划） | GitHub Pages（实际） |
|---|---|---|
| 前提 | 需 Vercel 账号 OAuth 或 VERCEL_TOKEN | 已有 GitHub 凭证（qintingye） |
| 本机可用性 | ❌ 无账号/token，`vercel login` 需交互 | ✅ 凭证已配置，API 可用 |
| 免费 | Hobby 免费 | 免费 |
| HTTPS | ✅ 自动 | ✅ 自动 |
| 密码保护 | 免费层无 Password Protection（Pro 才有） | 前端 HTML 门禁（PoC 级） |
| 持续托管 | ✅ | ✅（关本机也能访问） |

**结论**：Vercel 部署材料已就绪（`vercel.json` + 指南），但**无账号无法执行**；GitHub Pages 实现等价交付（公网 URL + 访问密码 + HTTPS），符合 ADR-004「公网 PoC 仅前端壳 + 演示数据」。

**迁移路径**：老板/团队若提供 VERCEL_TOKEN 或完成 Vercel 账号授权 → 按 `docs/W3-D2-Vercel部署.md` 步骤 5 分钟内迁到 Vercel（Root Directory=docs/preview 是关键）。
