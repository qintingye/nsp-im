## 方式 ② 本地服务器 · 5 分钟（内网演示）

> **适用**: 局域网内访问 / 离线演示 / 不想走公网

### 步骤

```bash
# 1. 启动（一次性）
cd D:/hermes-dev-team/nsp-im
python -m http.server 8080 --directory docs/preview

# 2. 访问
# 本机：http://localhost:8080
# 局域网：http://<本机内网IP>:8080（如 192.168.1.19:8080）

# 3. 停止：Ctrl+C
```

### 后台运行（Linux / Mac）

```bash
nohup python -m http.server 8080 --directory docs/preview > logs/preview.log 2>&1 &
```

### 后台运行（Windows · PowerShell）

```powershell
cd D:\hermes-dev-team\nsp-im
Start-Process python -ArgumentList "-m","http.server","8080","--directory","docs/preview" -WindowStyle Hidden
```

### 检查

```bash
curl -I http://localhost:8080/        # 应返回 200
curl http://localhost:8080/data/policies.json | head   # 应返回 JSON
```

**注意**: 内网 IP 可能随 DHCP 变化，访问失败联系 PM 重查 IP。

## 方式 ③ 分享文件 · 1 分钟（离线 / 现场）

> **适用**: 无网络演示 / 客户现场 / 邮件发送 / U 盘拷贝

### 步骤

```bash
# 1. 打包（zip）
cd D:/hermes-dev-team/nsp-im
powershell Compress-Archive -Path docs/preview/* -DestinationPath nsp-im-v1.0-preview.zip -Force

# 或 tar
tar -czf nsp-im-v1.0-preview.tar.gz -C docs/preview .
```

### 接收方使用

```bash
# 解压到任意目录
unzip nsp-im-v1.0-preview.zip -d nsp-im-v1.0

# 浏览器直接打开（最简单）
# 双击 docs/preview/index.html
# ⚠️ 注意：file:// 协议下 PWA / Service Worker 不生效，推荐走方式 ②

# 或本地起一个简单服务
cd nsp-im-v1.0
python -m http.server 8080
# 访问 http://localhost:8080
```

### 体积

| 项 | 大小 |
|---|---|
| docs/preview/ 原始 | ~5 MB（含字体） |
| docs/preview/ 不含字体 | ~700 KB |
| zip 压缩后 | ~3.5 MB / ~500 KB |
