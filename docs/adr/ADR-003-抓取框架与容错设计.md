# ADR-003 · 抓取框架与容错设计

> **状态**：已接受（2026-08-18）｜**类型**：架构决策
> **作者**：PM｜**关联**：ADR-001，src/fetchers/*

## 背景
平台依赖外部政策网站（发改委等），源站改版/限流/网络抖动不可避免；抓取失败不能导致数据损坏或静默丢失。

## 决策
1. **抽象基类 `BaseFetcher`**（src/fetchers/base.py）：
   - `fetch_raw()`（子类实现）→ `parse()`（标准化 dict）→ `save()`（去重+原子写入）
2. **容错四件套**：
   - 超时：默认 30s（可配置）
   - 重试：最多 3 次，指数退避（2^n 秒）
   - 失败告警：`alert_failure()`（W1 打日志，预留飞书 webhook + 邮件）
   - 死信队列：失败源写入 dead-letter（W1 预留 TODO）
3. **原子写入**：临时文件 + `replace()`，防止半写 JSON
4. **去重**：按 `id` 去重追加，不覆盖历史
5. **健康探针**（D3 落地）：抓取成功率 / 响应时间 / 数据新鲜度；失败不覆盖旧数据

## 后果
- 单源故障不影响数据可用性（旧数据保留）
- 源站改版 → Agent 自适应 + 失败告警兜底（风险登记 W1-风险2）
