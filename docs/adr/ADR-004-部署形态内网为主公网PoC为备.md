# ADR-004 · 部署形态：内网为主、公网 PoC 为备

> **状态**：待审批（2026-08-18 提交，需领导拍板）｜**类型**：部署决策
> **作者**：PM｜**关联**：ADR-005

## 背景
政策情报数据涉及政府公开信息二次整理与内部研判，公网暴露存在合规风险；同时团队需要远程演示能力。

## 决策
| 环境 | 用途 | 说明 |
|---|---|---|
| **内网（主）** | 正式运行 | 前端静态文件 + 数据 JSON 部署到内网服务器；审批通过后落地（D4 出预览） |
| **Vercel 公网（备/PoC）** | 演示与开发预览 | 仅部署前端壳 + 演示数据；**不部署真实政策数据** |

**约束**：
- 公网 PoC 不包含 `data/policies.json` 真实数据（.gitignore / 构建排除）
- 内网部署需领导审批（本 ADR 即审批申请单）
- 停损门：W1 末内网方案未审批通过 → 冻结扩源，仅保留本地 PoC

## 审批
- [ ] 领导审批（待拍板）→ 通过后 D4 执行内网部署预览
- 联系人：PM（已提交审批请求，见 W1-启动汇总「下一步 1」）

## 后果
- 公网与内网数据隔离，合规风险可控
- 演示链路：1 源 → JSON → 内网部署（D5 端到端演示目标）
