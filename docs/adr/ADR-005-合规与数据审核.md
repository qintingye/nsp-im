# ADR-005 · 合规与数据审核

> **状态**：已接受（2026-08-18）｜**类型**：治理决策
> **作者**：PM｜**关联**：ADR-002/004

## 背景
平台聚合政策文件与项目情报，需要明确「谁对数据合规负责」以及「数据如何流转到可发布状态」。

## 决策

### 1. 合规审核人（2026-08-18 PM 确认）
| 角色 | 职责 |
|---|---|
| **wdw-guanjia（质检员）** | 日常数据合规巡检：来源可追溯、字段完整、无敏感信息、schema 合法 |
| **老板/领导（最终审批人）** | 内网部署、对外发布、重大数据更正（决策 253：老板只验收不决策，但涉及对外发布需其批准） |

### 2. 数据合规要求
- **来源追溯**：每条 policy 必须带 `source_url` + `captured_at` + `captured_by`（schema 已约束）
- **review_status 状态机**：抓取落地 = pending → wdw-guanjia 巡检通过 = approved；不通过 = rejected（不进前端）
- **禁止内容**：不发布内部研判结论到公网；公网 PoC 不含真实数据（ADR-004）
- **版权提示**：政策原文转载注明来源；二次整理标注「据 XX 整理」

### 3. 巡检节奏
- wdw-guanjia 每日随抓取 CI 后巡检（D3 后自动化预检 + 人工抽检）
- 重大政策（priority≤2）逐条人工复核

## 后果
- 数据发布前有强制审核闸门，避免未审数据流出
- wdw-guanjia 纳入 NSP-IM 数据链路（跨项目复用其质检能力）
