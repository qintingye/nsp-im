## 💡 问题 (需 D31.1 确认)

### P1 - 总分列颜色与字面规则不一致
- **位置**: `.heatmap` 表 `<td>` 第 5 列 (总分)
- **现状**: 总分 8.0 / 8.8 / 8.9 渲染为黄色 (因使用 `s-8_0/s-8_8/s-8_9` 类 → `rgba(251,191,36,0.2)`)
- **字面规则**: ≥3.7 → 绿,3.1-3.4 → 黄,1.5-1.9 → 红
- **冲突**: 8.0/8.8/8.9 字面属于 ≥3.7 应为绿色
- **可能设计意图**: 维度分用 4 分制 (3.7-4.0 绿,3.1-3.4 黄,1.5-1.9 红),总分因范围 0-10 需新分段 (≥9 绿,8-8.9 黄)
- **建议**:
  - 选项 A: 确认设计意图,在 CSS 注释中补齐规则("总分 ≥9 绿 / 8-8.9 黄")
  - 选项 B: 改 `s-8_x` 为绿色系,与字面规则统一
- **影响**: 不影响数据正确性,仅 UX 解读;三种颜色齐全,2D 视觉清晰
