枢纽定位：新型电网

  • • 源-网-荷-储全要素配置能力
  • • 统一调度平台 + 跨网数据汇聚
  • • 唯一具备"算电/水电/冷电"双向调节能力的网
  • • 政策依据：1144/1360/1192/688 号文 + 新型电力系统行动方案

水网协同（最成熟）

  • • 抽水蓄能 + 梯级水电扩机增容（纲要 P3）
  • • 丰枯期水电-新能源动态平衡
  • • 汛期水情数据共享 → 电网保供
  • • 风险：极端水文年 + 龙头水库调度权

算力网协同（最高热）

  • • 阳江海底算电协同 1.15GW 标杆
  • • 韶关集群 4 万P 需稳定绿电
  • • 算力负荷纳入 VPP / 需求响应
  • • 风险：算电交易机制 + 绿证溯源

通信网协同（最易切入）

  • • 5G-A / 万兆光网嵌入电力场景
  • • 杆塔/管道/光缆基础设施共享
  • • 通信负荷"转改直" + 绿电交易
  • • 风险：跨行业数据互通标准

地下管网协同（最迫切）

  • • 综合管廊共建 + 一张图融合
  • • 极端气候下抢修协同（台风/洪涝）
  • • 城市生命线 90% 智能监测
  • • 风险：管廊权属 + 投资分摊

物流网协同（最大增量）

  • • 港口/枢纽充换电 + 园区微电网
  • • 冷库蓄冷 + 岸电纳入 VPP
  • • 绿色物流数字凭证（电-碳-绿证）
  • • 风险：交通能源融合统计口径
