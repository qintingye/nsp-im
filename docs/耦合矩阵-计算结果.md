### 6.2 项目权重表（PROJECT_WEIGHTS）

30 个项目 × 6 网 = 180 个权重值，存于 `src/prompts_v4.py` 的 `PROJECT_WEIGHTS` 列表，函数 `get_project_weights(project)` 单项目计算。

**权重计算方法**：
```
W_Ai = 投资×0.4 + 技术×0.3 + 政策×0.2 + 工程×0.1
工程因子 = 因子 × 推进批次成熟度
       (实施 0.95 / 前期 0.70 / 储备 0.55 / 谋划 0.45 / 研究 0.40)
```
