| **A. 灰色关联度** | 邓聚龙 1989 | 关联系数 ζi = (Δmin+ρΔmax) / (Δi+ρΔmax) | 适合小样本 | 计算复杂 |

## 三、推荐算法:**双网协同度模型 v1.0**

### 3.1 核心公式

```
耦合分(网A, 网B) = 项目数因子 × 利益因子 × 验证因子
                = f(N) × g(W) × h(V)
                = 满分 10 分
```

### 3.2 三大因子详解

#### 因子 1:项目数因子 f(N)(40% 权重,满分 4 分)

```
f(N) = min(协同项目数 / 5, 1.0) × 4

| 协同项目数 | 分数 |
|---|---|
| 0 | 0.0 |
| 1 | 0.8 |
| 2 | 1.6 |
| 3 | 2.4 |
| 4 | 3.2 |
| 5+ | 4.0 (满分) |
```

**设计理由**:5 项目 = 满分,鼓励完整覆盖

#### 因子 2:利益因子 g(W)(40% 权重,满分 4 分)

```
g(W) = (1/N) × Σ(项目i的共赢系数i) × 4

共赢系数i = √(W_Ai × W_Bi)
W_Ai = 项目i对网A的权重(0-1)
W_Bi = 项目i对网B的权重(0-1)
```

**权重矩阵示例**(基于实际南网项目):

| 项目 | 电网 | 水 | 算 | 通 | 管 | 物 |
|---|---|---|---|---|---|---|
| 阳江海底算力 | 0.9 | 0.0 | 0.95 | 0.0 | 0.0 | 0.0 |
| 韶关集群 | 0.85 | 0.0 | 0.90 | 0.0 | 0.0 | 0.0 |
| 海南算力一张网 | 0.7 | 0.0 | 0.85 | 0.0 | 0.0 | 0.0 |
| 中国-东盟数据专区 | 0.6 | 0.0 | 0.7 | 0.0 | 0.0 | 0.0 |
| 深广韶数据大通道 | 0.8 | 0.0 | 0.85 | 0.0 | 0.0 | 0.0 |

**电网 ↔ 算力共赢系数**:
```
g = (1/5) × (√(0.9×0.95) + √(0.85×0.9) + √(0.7×0.85) + √(0.6×0.7) + √(0.8×0.85)) × 4
  = (1/5) × (0.925 + 0.874 + 0.772 + 0.648 + 0.825) × 4
  = 0.809 × 4
  = 3.24
```

#### 因子 3:验证因子 h(V)(20% 权重,满分 2 分)

```
h(V) = (有政策 × 0.7 + 有投资 × 0.8 + 有工程 × 1.0) / 2.5 × 2

| 数据维度 | 权重 |
|---|---|
| 有正式政策文件 | 0.7 |
| 有投资金额 | 0.8 |
| 有在建/规划工程 | 1.0 |
```

**南网 5 源政策**:通常 3 维度都有,验证因子 ≈ 1.5-2.0

### 3.3 实际计算(电网 ↔ 算力网)

```
f(N) = 5/5 × 4 = 4.00
g(W) = 0.809 × 4 = 3.24
h(V) = 1.6 (3 维度都有)
总分 = 4.00 + 3.24 + 1.6 = 8.84 ≈ 8.8 ⭐
```

**等级**:
- 🟢 ≥ 8.0:**高分协同**(强双赢)
- 🟡 6.0-7.9:中等协同
- 🔴 < 6.0:弱协同/需关注

## 五、数据源(每项目)

| 数据点 | 来源 |
|---|---|
| **项目名称** | 5 源政策抓取(发改委/能源局/南网/国网/北极星) |
| **W_Ai 权重** | 项目对网A的实际依赖度(基于工程内容) |
| **W_Bi 权重** | 项目对网B的实际依赖度 |
| **验证数据** | 政策文件/投资金额/工程进度(3 维验证) |

**权重计算方法**:
```
W_Ai = (
    投资占比 × 0.4 +   # 该网在该项目中的投资比例
    技术依赖 × 0.3 +   # 该项目对该网的技术依赖
    政策提及 × 0.2 +   # 政策文件提及该网次数
    工程阶段 × 0.1     # 实施阶段
)
```

**示例**(阳江海底算力):
- 投资占比:电网 60%(电力基础设施)、算力 40%
- 技术依赖:电网 90%(依赖绿电直供)、算力 95%
- 政策提及:电网 5/8 篇、算力 8/8 篇
- 工程阶段:施工中(权重 1.0)

**W_电网 = 0.6×0.4 + 0.9×0.3 + 5/8×0.2 + 1.0×0.1 = 0.24+0.27+0.125+0.1 = 0.735 ≈ 0.9**
**W_算力 = 0.4×0.4 + 0.95×0.3 + 8/8×0.2 + 1.0×0.1 = 0.16+0.285+0.2+0.1 = 0.745 ≈ 0.95**
